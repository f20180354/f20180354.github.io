Research

Structure as a learning signal.

I work on learning algorithms for large models. My current projects study how model architecture, training dynamics, and formal task structure can guide optimization and inference.

01

Optimization for sparse models

Current work studies expert-specific optimization for Mixture-of-Experts models, including preconditioning, signal-to-noise gating, and excitation-based updates.

02

Queryable LoRA uses a shared memory of low-rank update atoms and state-dependent routing to make adapter updates depend on the current computation.
